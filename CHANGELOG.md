# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.0.0] - 2026-07-30
### Added
- Comprehensive test suite with pytest and shared fixtures.
- Complete CI/CD pipeline using GitHub Actions.
- Multi-stage Docker build and Docker Compose configuration.
- Standardized Makefile for cross-platform development tasks.
- Pre-commit hooks for automated code formatting and linting.
- Project documentation including CONTRIBUTING.md.

### Changed
- Refactored project metadata into pyproject.toml.
- Replaced unittest with pytest framework.

## [1.0.0] - 2026-07-21
### Added
- Initial release of SportRadar Tennis Analytics platform.
- Sportradar API integration and ETL pipeline.
- Interactive Streamlit dashboard.
- Base data transformers and quality checks.
