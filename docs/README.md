# Documentation

This folder contains project documentation, architecture details, API references, and validation deliverables.

## Contents

- `api_sources.md` — Information about Sportradar API endpoints and integration paths.
- `sql_queries.md` — SQL deliverables, query catalog, and documentation for analysis queries.
- `report.md` — Project report, summary of insights, and validation notes.
- `schema_design.md` — Schema design decisions for SQLite, PostgreSQL, and MySQL.
- `requirements_matrix.md` — Dependency compatibility and package guidance.

## Usage

Read the documentation in order for a complete understanding of the project:

1. `README.md` — repository overview and getting started.
2. `docs/README.md` — project documentation index.
3. `docs/report.md` — project summary and validation details.
4. `docs/sql_queries.md` — detailed query deliverables.
